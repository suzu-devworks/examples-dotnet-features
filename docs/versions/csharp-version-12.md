## Monologue

I started writing C# code seriously with Visual Studio 2003, so it was from that version.
It might have been quite early on.

At the time, I didn't even know version 1.2 existed;
I only recognized the differences between Visual Studio versions like 2002 and 2003.

Back then, each Visual Studio version was required,
so I had all versions—6.0, 2002, and 2003—installed on my computer for development.
