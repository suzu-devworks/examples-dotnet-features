## Monologue

At the time, VB6.0 was the dominant language. I never directly used C# 1.0; in fact,
I learned the .NET Framework incidentally while learning VB7.0.

Having missed the Java development boom, I wasn't inclined to immerse myself in Java, which was already widely used.
C# was truly a savior for me.

At the time, C# 1.0 felt like a rehash of Java. While Java at the time had a lot of boilerplate code,
C# was the same. However, I think it had the advantage of running on the Windows platform.

Ultimately, I wanted to call the Win32 API, and I remember frequently using PInvoke.
